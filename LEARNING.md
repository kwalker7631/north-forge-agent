# Learning device

This is not a search page with a nicer voice.

On a live call it may be thin until the shop has taught it. That is
normal. When someone supplies the missing procedure, that answer is
supposed to stay in memory and skills so the next session starts ahead.

On an admin PC that stays on and has a network, scheduled jobs
(`hermes` cron) should go out daily and gather **public** industry notes:
new products, firmware talk, forum threads. Those notes reinforce the
*pack* (logs, briefs, skills) — they do not retrain the raw model.

A stick in a drawer overnight does not crawl the web. It still keeps
what was already written to that stick.

Private manufacturer procedure lives in the private edition. Public
cron must not pull customer systems or paywalled service manuals into a
public repo.
