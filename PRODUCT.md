# North Forge is a go-to on the desk

Read [START_HERE.md](START_HERE.md) first if you do not want a vendor tour.

You already have Google and a chatbot. Techs still type **what is an F248**
and get a confident wrong paragraph. This stick exists so they do not have
to become prompt engineers on a live call.

North Forge is a portable support assistant: device, PC, network, PaperCut,
MyQ, the rest of the document stack the edition has been taught. An
administrator loads a private manufacturer pack (Kyocera today; Sharp,
Ricoh, Xerox later). The tech types ordinary English. It is supposed to
**show a knowledge gap instead of inventing a fix**, then keep the answer
once you supply it.

```
Public repo            = working stick, generic chassis
Private edition        = the actual TSC brain (this is the product)
Teammate experience    = plug in → Start North Forge → talk like a coworker
```

Details, limits, and the roadmap: [CAPABILITIES.md](CAPABILITIES.md).  
New manufacturer pack: [editions/OEM.md](editions/OEM.md).
