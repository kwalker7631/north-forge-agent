# North Forge is a go-to on the desk

Read [START_HERE.md](START_HERE.md) if you want the reason.
Read [CAPABILITIES.md](CAPABILITIES.md) if you want the inventory.

You already have search and a chatbot. Technicians still get a confident
wrong paragraph on a live call. This drive exists so they do not have to
become prompt engineers while a customer waits.

North Forge is a portable support assistant: device, PC, network,
PaperCut, MyQ, and the rest of the stack the edition has been taught. An
administrator loads a private manufacturer pack. The technician types
ordinary English. It is supposed to **show a knowledge gap instead of
inventing a fix**, then keep the answer once you supply it.

```
Public repo         = working chassis
Private edition     = the TSC brain (this is the product)
Teammate experience = plug in → Start North Forge → talk like a coworker
```

New manufacturer pack: [editions/OEM.md](editions/OEM.md).
